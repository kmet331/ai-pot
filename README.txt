[GitHub에 올리는 방법]  (저장소: kmet331.github.io/ai-pot)

1) GitHub의 ai-pot 저장소 → Add file → Upload files
2) 이 폴더 안의 파일 중 README.txt를 뺀 8개를 "전부" 한꺼번에 끌어다 놓기
   (폴더째가 아니라 파일들만! 기존 index.html은 자동으로 덮어써져요)
     index.html
     manifest.webmanifest
     favicon.ico
     favicon-32.png
     apple-touch-icon.png
     icon-192.png
     icon-512.png
     icon-maskable-512.png
3) Commit changes → 1~2분 뒤 접속해서 확인

[올린 뒤 확인할 것]
- 탭에 분홍 마스코트 아이콘이 보이는지
  (안 바뀌어 보이면 Ctrl+Shift+R 강력 새로고침. 브라우저가 파비콘을 오래 기억해요)
- 안드로이드 Chrome: "홈 화면에 추가" 버튼 → 설치 팝업이 뜨는지
- 아이폰 Safari: 버튼 → 3단계 안내창 → 실제로 홈 화면에 추가되는지
- PC Chrome/Edge: 버튼 → 설치 팝업 → 바탕화면 바로가기 생성되는지

[참고]
- 이미 홈 화면에 추가해 둔 학생은 아이콘이 옛 모양일 수 있어요(삭제 후 다시 추가하면 새 아이콘).
- 문제를 수정해서 다시 올려도 학생 화면에는 새로고침하면 바로 반영돼요(오프라인 캐시를 쓰지 않음).
